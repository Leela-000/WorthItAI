# Milestone 1 – Sprint Plan

## Project
**WorthIt AI – AI-Based Startup Idea Validator with Market Analysis Assistance**

**Team:** Team Orion

## Sprint Objective
To develop the initial version of WorthIt AI with startup idea submission, LLM-based idea extraction and web search assistance.

## Planned Tasks

| Task | Description |
|---|---|
| Research | Study startup validation frameworks, multi-agent design patterns and web search APIs |
| Architecture | Define system architecture, agent roles, orchestration flow and data models |
| Frontend | Develop the startup idea submission and extraction pages |
| Backend | Develop FastAPI endpoints and integrate SQLite |
| LLM Integration | Use Groq for structured startup idea extraction |
| Web Search | Integrate Tavily for retrieving relevant market information |
| Integration | Connect frontend with backend and display actual results |
| Documentation | Prepare README, research note and architecture documentation |

## Expected Deliverables
1. Startup idea submission page.
2. Structured idea extraction using Groq.
3. Working Tavily web search agent.
4. System architecture and data model documentation.
5. Research note comparing frameworks, agent patterns and search APIs.
6. README and Agile documentation.

## Sprint Completion Criteria
- Frontend communicates with the backend.
- Submitted ideas are processed by the LLM.
- Web search returns relevant results and source URLs.
- Required documentation is available in the GitHub repository.

## Note
This document describes the planned Milestone 1 scope. Task completion should be updated according to actual team progress.
